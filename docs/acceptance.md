# Приёмка: помощник ведущего «Мафии»

Дата: 2026-11-14, дополнено 2026-11-15, 2026-11-21 и 2026-11-22. Сценарий — раздел 8 спецификации (`docs/superpowers/specs/2026-11-14-mafia-host-design.md`), раздел 8 дополнения «Свои роли» (`docs/superpowers/specs/2026-11-15-custom-roles-design.md`, шаг 12), три этапа дополнения «Механики партии и новые роли» (`docs/superpowers/specs/2026-11-21-mechanics-and-roles-design.md`, шаги 13, 14 и 15), дополнение «Сигналы таймера и фолы» (`docs/superpowers/specs/2026-11-22-sound-and-fouls-design.md`, шаг 16) и дополнение «Раздача с учётом прошлых игр» (`docs/superpowers/specs/2026-11-22-history-aware-deal-design.md`, шаг 17).

## Как проверялось

- **Что открывалось:** собранный `dist/index.html`, открытый с диска по адресу `file:///…/dist/index.html`. Сервер не запускался.
- **Браузер:** Google Chrome 157 на macOS, без окна, под управлением протокола DevTools. Клики — настоящие события мыши по координатам кнопок, клавиши Enter и цифры — настоящие события клавиатуры.
- **Кто проходил:** скрипт `scripts/acceptance.mjs`, а не человек. Повторить: `npm run build`, затем `npm run acceptance`.
- **Раздача случайная**, как в настоящей игре. Скрипт читает роли со стола и подбирает номера под сценарий, поэтому номера в прогоне отличаются от номеров в тексте спецификации (например, доктор лечит не обязательно №4).
- **Итог последнего прогона (2026-11-22, после раздачи с учётом прошлых игр):** 159 проверок из 159 прошли, два прогона подряд на итоговой сборке: 78 в шагах 1–12, 19 в шаге 13, 18 в шаге 14, 18 в шаге 15, 14 в шаге 16, 9 в новом шаге 17 и 3 общие. За весь сценарий в консоли нет ошибок и исключений, страница не сделала ни одного сетевого запроса. До раздачи с учётом прошлых игр было 150 из 150, до правки о накоплении наказаний за фолы — 149 из 149, до фолов — 136 из 136, до очереди начинающих — 131 из 131, до этапа 3 — 113 из 113, до этапа 2 — 94 из 94, до этапа 1 — 73 из 73.
- **Прогон может прерваться на шагах 3, 7 или 8 из-за раздачи.** Скрипт в этих шагах всегда начинает круг с №5. Если №5 оказался вторым или четвёртым по счёту мирным, сценарий сам выводит его из игры раньше (выстрел после правки или голосование), и кнопки «Выбрать игрока №5» нет. Это недочёт скрипта, а не приложения; он был и до шага 12. При таком сбое прогон надо повторить. Шаги 1–11 в этой работе не менялись. Прогон, который пересекает 6:00 утра по часам ноутбука, прервётся на шаге 17: игры прошлых шагов окажутся во вчерашнем игровом дне.

Автоматические тесты: `npm run check` — 640 тестов (движок, хранилище, состояние приложения, интерфейс, сценарные партии на движке, тесты на найденные недочёты в `tests/regression/`), типы и линтер проходят. После первой версии было 258 тестов, после этапа 1 — 333, после этапа 2 — 375, до очереди начинающих — 510, после фолов — 562, после правки о накоплении наказаний — 577. До дополнения приёмочный сценарий пройден трижды (52 из 52): до независимого ревью, после исправлений по нему и после сверки со спецификацией.

## Свои роли (дополнение от 2026-11-15)

Ведущий сам заводит роли на экране «Новая игра»: название, цвет, ходит ли ночью. Сделано по плану `docs/superpowers/plans/2026-11-15-custom-roles.md`, шесть задач, на каждую — коммит. `npm run check`, `npm run build` и `npm run acceptance` (73 из 73) пройдены после исправлений по ревью.

**Что сделано.**

- Движок: справочник ролей собирается на лету (встроенный плюс свои роли); ночное действие «запись» не участвует в расчёте итога ночи; блок проститутки, серый шаг, несколько носителей и обмен ролей работают для своей роли по общим правилам.
- Хранение: перечень ролей лежит в настройках браузера, игра хранит копию участвующих ролей. Негодные записи перечня пропускаются; игры без поля `customRoles` открываются.
- Экран состава: строка своей роли, форма «Новая роль» и «Изменить роль», предел в восемь ролей, колода, блок «Ночью просыпаются».

**Решения, принятые по ходу** (заказчик может поменять):

- Название своей роли показано по образцу встроенных: внутри фразы, на карточке, в колоде и в блоке «Ночью просыпаются» — со строчной буквы («Кого выбирает журналист?»), в начале строки — с заглавной («Журналист → №9»). Аббревиатура, у которой вторая буква прописная («КГБ»), не меняется. В форме правки роль показана так, как её ввёл ведущий.

Роль, которой не было в последнем розданном составе, в следующей игре остаётся выключенной. Цена: роль, выключенную без раздачи, приложение после возврата на экран состава включит снова — черновик состава между заходами не хранится.

**Что исправлено после независимого ревью.** Изменения прошли одно независимое ревью (свежий агент, весь дифф и окружающий код). Критических находок нет. Исправлено, на каждое исправление есть тест:

## Механики партии, этап 1: правила партии и ход дня (дополнение от 2026-11-21)

Сделано по плану `docs/superpowers/plans/2026-11-21-mechanics-and-roles.md`, задачи 1.1–1.8, на каждую — коммит. Этап 2 описан ниже, этап 3 (пять новых ролей) не начинался. На момент сдачи этапа 1: `npm run check` (333 теста, типы, линтер; до этапа было 260), `npm run build` и `npm run acceptance` (94 из 94, три прогона подряд) пройдены.

**Что сделано.**

- Правила партии в настройках игры: балаган, прощание после голосования, прощание после ночной смерти, когда просыпается проститутка. Блок «Правила партии» на экране состава; «Сбросить к стандарту» возвращает умолчания; следующая игра начинается с правил предыдущей.
- Балаган выключен — шага нет ни в один день. Прощание после голосования выключено — выгнанный выбывает так же, главная кнопка «№N выгнан → Ночь N» ведёт сразу в ночь (обычный исход, единственный кандидат, «Выгнать другого…», решение при второй ничьей).
- Роли скрываются в начале дня и открываются в начале ночи, в том числе при «Отменить» перехода фазы.
- День 1: случайный начинающий одной пачкой с началом дня, «Выбрать другого…», доп. речь первых двоих после круга, «Пропустить доп. минуту».
- Проститутка просыпается первой или после мафии — по правилу партии; опция роли «Блок крёстного отца отменяет: выстрел / поиск шерифа / выстрел и поиск» с предупреждением про порядок.
- Красный блок на шаге заблокированной роли, красная пометка шага, красная метка на карточке, строка «Заблокированы: …» на итоге ночи.
- Игры, сохранённые до обновления (без новых правил и без опций ролей), открываются и доигрываются по-прежнему.
- Все новые строки есть на русском и украинском.

**Решения, принятые по ходу** (заказчик может поменять):

- **Старый «последний состав».** Игра, сохранённая до обновления, получает прежние правила, а «последний состав» из настроек браузера (черновик новой игры) — умолчания новой игры: правил, которых в нём не было, ведущий не выбирал. Поэтому первая «Новая игра» после обновления предложит «Проститутка просыпается: Первой».
- **Отмена начала Дня 1** возвращает на экран распределения с ролями, скрытыми как в момент отмены: сами роли не открываются. Показать их — кнопкой на экране.
- **Кто получает доп. минуту, если один из первых двоих выбыл:** начинавший и следующий за ним по кругу игрок в игре — выбывшего заменяет следующий.
- **«Выбрать другого…»** снимает запись «(случайно)» из журнала, только пока по случайному выбору никто не говорил. После первой речи это «Начать круг заново»: прежняя запись остаётся, как остаются записи обычных кругов.
- **Блок при скрытых ролях** виден на шаге, но без номера игрока, без красной метки на карточке и без строки на итоге ночи. Иначе «№6 заблокирован» на шаге «Шериф» выдавал бы, что №6 — шериф. Номер открывается кнопкой «Показать роли» или клавишей H.
- **Пометка «заблокирован» в полосе шагов** стоит у шага, действие которого блок отменил. Заблокирована рядовая мафия при живом крёстном отце — пометки шага нет, а красный блок на шаге мафии есть: «На выстрел это не влияет».
- **Крёстный отец заблокирован, а опция поиск не отменяет:** на его шаге красный блок с «На поиск шерифа это не влияет» — по образцу утверждённого «на выстрел не влияет»; показать игроку блок всё равно надо.

**Решения, принятые по ходу** (заказчик может поменять):

- **Сводки «Что записано этой ночью» на итоге больше нет.** На утверждённом макете её нет; записи шагов видны в полосе шагов над итогом и в журнале. Цена: ответ шерифа на итоге не повторяется.
- **Итог при скрытых ролях.** Список «Покидают стол» виден и правится, но в нём только номера с отметками; причин, «Остаются в игре», строки про блок и «Не записано» не видно, главная кнопка — «Подтвердить итог · начать День N». Раньше при скрытых ролях итог не показывался совсем.
- **«Добавить выбывшего…» добавляет строку, а не подтверждает итог сразу** (прежняя «Выбыл другой…» подтверждала). Вторичной кнопки «Никто не выбыл» больше нет: это снятая отметка.
- **Добавленный ведущим записывается застреленным:** своей причины у ручной отметки нет. Другую причину можно поставить из панели игрока.
- **Отметки на итоге — состояние экрана, а не журнала:** после «Назад к шагам ночи» и обновления страницы подсказка считается заново, снятые и добавленные отметки пропадают.
- **Подпись под «Застрелен мафией» — «никто не лечил»,** без «и не защищал» с макета: охранник — роль этапа 3.

2. **Очередь жертвы маньяка в круге** сделана отдельным нажатием: «№4 молчит · ход без речи», затем «Следующий: №5 · 60 с». Нажатие нужно, чтобы жертва могла выставить в свой ход. Если удобнее пропускать её автоматически (а выставлять от её имени из панели игрока) — скажите.
3. **Итог ночи при скрытых ролях** (решение этапа 2, на него указало ревью). Список «Покидают стол» с номерами виден и при скрытых ролях — без причин и заметок; иначе итог нельзя было бы править, не открыв роли. Оставить или при скрытых ролях не показывать ничего, как было до этапа 2?
4. **Красный блок при скрытых ролях** (решение этапа 1, на него указало ревью). Блок на шаге роли виден, но без номера игрока: «№6 заблокирован» на шаге «Шериф» выдал бы шерифа. Это отступление от буквы раздела 5.4 («блок виден и при скрытых ролях»). Оставить так?

**Решения, принятые по ходу** (заказчик может поменять):

- **Запреты выбора — жёсткие там, где спецификация говорит «нельзя»:** охранник не может выбрать себя; журналист — себя, уже проверенного, игрока с открытой ролью. Карточки заперты, запись отклоняется. Повтор цели у охранника и маньяка — предупреждение с «Записать всё равно».
- **Несколько охранников.** Число охранников не ограничено. Двое защищают одного — нападение принимает первый по номеру; принятое нападение дальше не переходит.
- **В охранника стреляли напрямую, и он же закрыл подзащитного** — он погиб «вместо подзащитного» и прощается.
- **Цель, выбывшая вручную посреди ночи.** Охранник за неё не гибнет, маньяк к ней «не приходил», журналист её не сравнивает. Выстрел, удар мясника, лечение, блок и проверки считаются по записанной цели, как раньше: подсказка может назвать выбывшим того, кто уже выбыл.
- **Ведущий сам отметил игрока в жилете выбывшим** («Добавить выбывшего…», «Застрелен» в панели) — он выбывает: ручная отметка — решение ведущего.
- **Жилет привязан к месту:** после «поменять роли» события жилета за ролью не переезжают; поправить можно кнопкой в панели игрока.
- **Правка прошлой ночи и жилет.** Правка записи жилет не трогает; «Исправить» снимает и возвращает жилеты по пересчитанной подсказке, «Оставить» — нет. Правка самого итога («Итог ночи» в журнале) жилет не трогает.
- **Главная кнопка называет жилет заранее:** «№5 в бронежилете — остаётся → Ночь 2» — и при скрытых ролях: исход «выгнан» уже известен столу, роль открывается в следующую секунду.
- **«Снять жилет» при скрытых ролях не показывается** (кнопка назвала бы роль); «Вернуть жилет» у снятого — показывается.
- **Кто сегодня молчит,** выводится из записей прошлой ночи и текущих статусов: ведущий снял отметку с убитого повторным визитом — он в игре и молчит; жертва выбыла — метки нет; вернули в игру — снова молчит.
- **Спасённый от повторного визита** (доктором, охранником, жилетом) всё равно завтра молчит; на итоге ночи у него две строки.
- **«Две ночи подряд» у маньяка** считается по записанной цели прошлой ночи, даже если тот визит заблокировали, — как у доктора.
- **«Не выставляет»** — на экране: кнопки «№4 выставляет…» нет. Запись выставления от имени жертвы из журнала движок принимает.
- **В ход молчащего пробел ничего не делает:** таймера нет, слово дальше передаёт главная кнопка.
- **«Уже проверен» у журналиста** считается для каждого журналиста отдельно. «Никого» и заблокированная проверка никого не расходуют и отдыха не требуют. Повторную проверку одного игрока, если она случилась за столом, записать нельзя.
- **Скрытые роли на шагах охранника и журналиста:** запертых «по правилу» карточек нет — запертая выдала бы, кто охранник или журналист и кого он уже проверял. Выбор, который правило запрещает, движок не записывает, на шаге появляется строка «Не записано: этого игрока на этом шаге выбрать нельзя».
- **Своя роль ведущего с названием встроенной** («Журналист», «Маньяк») остаётся с пометкой «своя роль»; её можно править, не меняя названия. Новую с таким названием создать нельзя — в том числе «Мясник», «Різник», «Охранник», «Бронежилет».
- **«В составе нет мафии»** показывается и в составе с мясником без мафии: одиночка мафию не заменяет.
- **Счётчик «сам за себя»** на экране состава виден при числе больше нуля; в шапке игры — если одиночка роздан (остаётся «0», когда выбыл). Победителем одиночка предлагается, если его роль роздана, в том числе выбывший.
- **Строки «никто не стрелял», «стрелявший заблокирован», «цель вылечена»** оставлены и для игры с мясником и маньяком; для жилета добавлена «удар принял бронежилет».
- **Подпись третьего правила партии** теперь называет охранника: «…охранник, погибший защищая, прощается всегда».

Расчёт выстрела, лечения, блока и проверок возвращён к прежнему.

Теперь утро считается объявленным, если день уже идёт; «Отменить» в окне есть, только пока последнее действие — подтверждение ночи.
- **Ход молчащего:** на карточке стояли «говорит сейчас» и «молчит» вместе; «Выставить» из панели игрока писалось без автора.

## Очередь начинающих (дополнение от 2026-11-22)

Просьба заказчика: начинающий круг запоминается, и на следующий день приложение само ставит следующего. День 1 начинал №3, закрывали №3 и №4 — День 2 начинает №5 (без доп. минуты), День 3 — №6 и так далее; выбывший пропускается. Правило записано в дополнении `docs/superpowers/specs/2026-11-21-mechanics-and-roles-design.md`, раздел 5.1.

`npm run check` (527 тестов, типы, линтер; до работы было 510), `npm run build` и `npm run acceptance` (136 из 136) пройдены.

### Что сделано

- Со второго дня начинающий ставится вместе с началом дня: кнопка итога ночи одним действием подтверждает ночь и открывает круг по очереди; «Отменить» возвращает на итог ночи одним нажатием.
- День 2 — следующий игрок в игре после второго из закрывавших День 1; День 3 и дальше — следующий после вчерашнего начинавшего. Выбывшие пропускаются, после последнего номера очередь переходит к №1.
- В полосе шагов пометка «День 2 · круг начинает №5, по очереди», в журнале «Круг начал №5 (по очереди)», на карточке «начинает день» (после его речи — «говорил · начинал день»).
- После балагана, «Пропустить балаган» и ночного прощания приложение не спрашивает, кто начинает: кнопка «К кругу речей · начинает №5» сразу открывает круг.
- «Выбрать другого…» работает, пока в круге никто не говорил; завтра очередь идёт от выбора ведущего.
- Окно утра открывается как раньше: автоматическая запись о начинающем не считается началом дня.

### Решения, принятые в работе

- **Ведущий может выбрать другого.** Журнал не решает за ведущего; так же устроен случайный выбор в День 1.
- **Запись «по очереди» хранит правило, а не номер.** Пока круг не начался, очередь идёт по нынешним статусам: ведущий после начала дня поправил итог ночи (отметил выбывшим того, кто должен был начинать, или вернул в игру ошибочно отмеченного) — начинающий сменился сам. С первого хода круга начинавший закреплён: если он выбыл позже, завтра очередь всё равно идёт от него.
- **Кто закрывал День 1** — первые двое на момент последней доп. минуты, как их видел ведущий. Доп. минуты пропустили или не дошли до них — считается пара по статусам на конец Дня 1.
- **Вчера круг не открывали вовсе** (ведущий сразу ушёл в ночь, не дав слова никому и не выбрав начинающего) — очереди нет, начинающего выбирает ведущий, как раньше.
- **Круг начат заново** («Начать круг заново с №…») — начинавшим дня считается тот, с кого начат последний круг.
- **Метка на карточке** до речи начинающего читается «начинает день»: раньше и в День 1 там стояло «начинал день» ещё до первой речи.

### Что проверено

- Тесты `tests/engine/next-opener.test.ts` (11) и `tests/ui/next-opener.test.tsx` (6): очередь по дням, пропуск выбывших и переход к №1, выбор ведущего, правка статусов до и после начала круга, выбывший после доп. минуты закрывавший, запись журнала, кнопки после балагана и ночного прощания, метка карточки, одна отмена на подтверждение ночи и выбор начинающего.
- Приёмочный сценарий: в шаге 3 — кнопка после балагана называет следующего по очереди, пометка в полосе шагов, «Выбрать другого…» её снимает; в шагах 7 и 8 — Дни 3 и 4 начинает следующий после вчерашнего начинавшего; в шаге 13 — День 2 без балагана открывается кругом с выбранным по очереди.

- Каждый сигнал — один раз; «+10 с» при остатке меньше десяти секунд возвращает отметку, и предупреждение звучит снова; на паузе и после сна предупреждения нет.

### Решения, принятые в работе

- Одна кнопка звука в шапке выключает оба сигнала; отдельной настройки предупреждения нет.
- Предупреждение тише и ниже сигнала конца, чтобы не перебивать говорящего и отличаться на слух.
- Таймер длиной 10 секунд и короче не предупреждает.

### Что проверено

- Тесты движка и интерфейса (см. спецификацию, раздел 1.4).
- В браузере (Chromium, собранная страница на `localhost`): часы страницы сдвинуты к отметке — при остатке 10 секунд созданы два тона 660 Гц, по нулю — 880, 880 и 1175 Гц, панель мигает; повторов нет.

## Фолы (дополнение от 2026-11-22)

Просьба заказчика: фолы за перебивание и речь не в свою очередь; три фола — игрок один день не говорит, может только выставить; наказание ведущий применяет или отменяет в окне подтверждения, фолы считаются всегда. Правила и решения — в `docs/superpowers/specs/2026-11-22-sound-and-fouls-design.md`, раздел 2.

`npm run check` (562 теста, типы, линтер; до работы было 535), `npm run build` и `npm run acceptance` (149 из 149, два прогона подряд) пройдены.

### Что сделано

- Фол из панели игрока в любой фазе после раздачи; счёт за игру на карточке и в панели, виден при скрытых ролях; «Снять фол».
- Каждый третий фол открывает окно «Наказание за фолы»: «Применить наказание», «Не применять», «Отменить фол».
- Наказание — один день без своей минуты в круге: сегодня, если игрок ещё ждёт слова, иначе завтра. В свою очередь — ход без речи и без таймера, выставить можно.
- Решение меняется в панели игрока; утреннее окно называет наказанного; записи в журнале.
- Новый шаг 16 приёмочного сценария.

### Решения, принятые в работе

Список — в спецификации, раздел 2.6. Главные: порог — каждый третий фол (3, 6, 9…); день наказания — ближайшая своя очередь игрока в круге; у наказанного остаются оправдание, речь при ничьей, прощание и голос; макеты в Claude Design не рисовались. Моё решение «два порога подряд дают два дня без речи» заказчик отменил — см. «Правка заказчика» ниже.

### Что проверено

- Тесты движка (28) и интерфейса (14): счёт по фазам, пороги, день наказания сегодня и завтра, отказ, смена решения, снятие фола, шесть фолов до отбытого наказания, пропущенный порог и порог после отбытого наказания, чужое наказание, отбытое наказание окончательно, два решения у одного игрока, круг, начатый заново, выбывший и возвращённый, доп. минута Дня 1, утро, журнал на двух языках, окно и клавиши, опции маньяка рядом с наказанием.
- Приёмочный шаг 16 в Chrome без окна: счёт и «Снять фол», окно на третьем фоле, «Отменить фол», наказание сегодня (ход без речи и без таймера), шесть фолов до отбытого наказания, наказание на следующий день и строка утра, выставление наказанным, «Не применять» и панель, журнал, обновление страницы.
- Снимки окна наказания (на русском и украинском), панели игрока и стола с метками сняты Chrome без окна с собранной страницы и просмотрены. После правки о накоплении наказаний панель игрока переснята: три фола с неотбытым наказанием и шесть фолов до отбытого наказания.

### Правка заказчика от 2026-11-22: наказания не накапливаются

Заказчик о моём решении «шесть фолов до отбытого наказания — два дня без речи»: «тут давай сделаем один день без речи, наказания до исполнения не накапливаются. накапливаются фолы».

- Пока у игрока есть неотбытое наказание (ход без речи ещё впереди), новые фолы считаются, но нового наказания не дают: окно на таком пороге не открывается, день без речи остаётся один.
- Порог, пришедшийся на неотбытое наказание, позже не возвращается; после отбытого наказания спрашивает очередной третий фол. Это моё уточнение к словам заказчика, как и то, что считать неотбытым, — спецификация, раздел 2.2.
- Панель игрока: кнопки относятся к последнему решению, даже когда фолов стало больше; под строкой о неотбытом наказании — пояснение. В журнале такой фол записан с пометкой.
- Независимая проверка правки: три агента с разными углами (правила движка; экран и тексты; документы и тесты), каждую находку перепроверил скептик. Найдено и исправлено до сдачи:
  - отбытое наказание можно было «Отменить» и снова «Применить» в панели игрока — оно переезжало на следующий день, и одно решение давало два дня без речи. Теперь отбытое наказание окончательно: кнопок нет, команда отклоняется;
  - после круга, начатого заново, панель показывала отказ по шестому фолу рядом с пояснением о неотбытом наказании, а «Применить наказание» добавляла второе. Теперь кнопки относятся к неотбытому наказанию, если оно есть;
  - тесты не ловили поглощение порога чужим наказанием, случай двух решений у игрока и границу «ход без речи начался» — добавлены и проверены намеренной поломкой кода.
- Не исправлялось, записано как решение (спецификация, раздел 2.6, пункт 11): если день наказания прошёл без хода игрока (ведущий не дал слова, игрок был вне игры), наказание считается отбытым.
- Проверено: `npm run check` (577 тестов, типы, линтер; до правки было 562), `npm run build`, `npm run acceptance` (150 из 150, два прогона подряд).

## Раздача с учётом прошлых игр (дополнение от 2026-11-22)

Просьба заказчика: вторая кнопка раздачи, которая смотрит на игры текущего игрового дня, даёт всем поиграть за активные роли и реже повторяет номеру ту же роль; судить только по номерам; полный рандом остаётся отдельной кнопкой. Правила, модель и решения — в `docs/superpowers/specs/2026-11-22-history-aware-deal-design.md`, план — в `docs/superpowers/plans/2026-11-22-history-aware-deal.md`.

### Что сделано

- Раздача по весам в движке: вес номера втрое меньше за каждую активную игру и ещё втрое — за каждый повтор той же роли. Мафия и глава мафии — одна роль; бронежилет и свои роли без ночного хода не считаются активными.
- Учитываются игры текущего игрового дня (с 6:00 до 6:00), дошедшие до Ночи 1; «Начать отсчёт заново» с «Вернуть».
- Экран состава: «Раздать случайно» и «Раздать с учётом прошлых игр», пояснение, счётчик со временем игр, предупреждение о числе мест.
- Экран раздачи: строка о способе раздачи, окно «Перераздать» с двумя способами; способ записан в журнале.
- Новый шаг 17 приёмочного сценария.

### Решения, принятые в работе

Ответы заказчика: сила учёта «мягко», затем «втрое реже» — после того как он увидел числа утечки; игровой день с 6:00 и сброс. Решения автора — в спецификации, раздел 8; главные: активная роль — роль с ночным действием (определение заказчика из дополнения «Свои роли»), учитываются игры с Ночи 1, сброс без окна подтверждения, Enter остаётся на случайной раздаче.

- **Двойной клик по файлу в обычном окне Chrome.** Файл открывался по адресу `file://` в Chrome без окна. Путь загрузки тот же, но буквально двойным кликом в видимом окне приложение не открывалось.
- **Звук сигнала по нулю.** У Chrome без окна нет звукового выхода. Тестами проверено только, что сигнал вызывается один раз в момент нуля, не вызывается при выключенном звуке и не повторяется после «сна».
- **Экран не гаснет.** Проверено только, что приложение просит об этом браузер во время игры и отпускает на паузе (тест с подставным окружением). Настоящее поведение ноутбука не проверялось.
- **Сон ноутбука на пять минут и недоступное хранилище (приватное окно, переполнение).** Только тесты с поддельными часами и поддельным хранилищем, не настоящий браузер.
- **«Речь закончена за 20 секунд»** в шаге 3 пройдена как «следующему дали слово раньше нуля»: речи прерывались через 1–3 секунды, двадцать секунд сценарий не ждал.
- **Часть экранов не сверялась с макетами по снимкам:** панель второй ничьей, речи при ничьей, оправдания и прощание, редактор записи журнала, настройки таймеров, шторка паузы, список игр на главной, украинский интерфейс (длина строк). Их поведение покрыто тестами и приёмочным сценарием, внешний вид — нет.
- **Полная партия на 20 игроков** не игралась, проверен только стол.
- **Другие операционные системы и другие браузеры** не проверялись.
